## CORS & Tickerbot API

Live browser calls from StackBlitz to https://api.tickerbot.io are subject to CORS and could not be verified from this offline tree. The app surfaces network/CORS failures gracefully (NETWORK OR CORS ERROR / UNAVAILABLE states) and deliberately includes NO fake proxy or mock. A local dev proxy pass-through (e.g. a Vite devServer proxy or a tiny Node server forwarding to api.tickerbot.io) is the intended workaround — it is not part of this repo.

## Troubleshooting: StackBlitz console errors (non-issues)

If you open this repo in StackBlitz and see console errors, most of them are generated by the StackBlitz editor itself and are not caused by app code. They are safe to ignore. The known ones:

1. **json.schemastore.org CORS errors (tsconfig/package/prettierrc)** — These are generated by the StackBlitz editor's IntelliSense fetching JSON schemas for `tsconfig.json`, `package.json`, and `.prettierrc` from json.schemastore.org. They are NOT produced by app code: this repo has no reference to json.schemastore.org anywhere. They are harmless and cannot be fixed from code.

2. **'Could not find source file: stackblitz:/...' errors** — If you see these for `api.js`, `app.js`, `utils.js`, `alerts.js`, `assets.js`, `charts.js`, `config.js`, `storage.js`, `ai-engine.js`, `indicators.js`, `market-data.js`, `build-check.mjs`, `notifications.js`, `Marketanalysis.js`, `pattern-engine.js`, `prediction-engine.js`, and `tests/tests/smoke.mjs`, the cause is that the open project is a stale 'HTML/CSS/JS Starter' instance (`stackblitz-starters-nkss5wfa`) whose file tree is out of date. All of those files exist in this repo, and both `node build-check.mjs` and `npm run smoke` pass. The stale tree even references the doubled path `tests/tests/smoke.mjs`, while this repo has `tests/smoke.mjs`. Fix: open the GitHub-synced project via the StackBlitz link in the README header (https://stackblitz.com/~/github.com/branagh88/node-3tradingapp) or re-import this repo, then refresh.

3. **'preloaded using link preload but not used' warning for fetch.worker.017acfb7.js** — This is a benign browser hint and can be ignored.
